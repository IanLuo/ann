Before S5 (planner kernel) lands, we amend the format so every task type has a real, lockable artifact. Code tasks currently have no artifact type — their artifact IS the git commit, and the spec has no shape for that. D1 — how many artifact kinds position: two — document + code

Position: two kinds — document (readable) and code (git). Records (provenance, binding results, closure transfers) are already events with their own invariants; making them a third kind adds JSON-locking machinery for something the event log already does.

Alternative: a third record kind — binding results lockable and supersedable like docs (more machinery, more uniform resolution).

D3 — code artifact identity position: commit SHA + target dirs

Position: generalize the frozen artifact-locked {name, path, lockSha} — lockSha becomes a git-object SHA (commit; verifiable via git cat-file -t), path = repo-relative target dir(s). current(name) resolution unchanged. Supersession = same name, new commit → superseded event, exactly like docs.

Alternative: commit ranges (from..to) — more precise but fragile to history rewrites; the logical-name resolution makes the single commit sufficient.

D4 — artifact gate & the §6/§7 contradiction position: required for doc/code, satisfied-by-events for records

Position: make artifact-locked required for completion of document/code tasks; record tasks satisfy it via events. This makes flow-control §6 ("done ⇔ artifact recorded") true for every task and resolves the §6-vs-§7 contradiction (implementation's artifact = the commit). Task 04 (S1) is grandfathered as-is — it's done and its gates are accepted.

Alternative: keep completion artifact-optional (less churn, but §6 stays false and the gate stays weakly enforced).

D5 — sequencing position: dedicated task, before S5

Position: a dedicated sibling task 06-engine-build/13-format-amendment-v9 via the change protocol — owns format spec v9 + flow-control amendment + vocab registry + cmdLock + store verification — landing before S5 (task 08 spawns children; the artifact gate bites there).

Alternative: fold into S5 — cheaper, but S5 builds on an unamended contract (the exact failure this system exists to prevent).
